# E1 历史对比记忆 · 盲评打分表

## 实验说明
- 3 只股票 × 2 个版本（A 无历史注入 / B 注入该股历史报告骨架），**单变量控制**——两版都走裸 analyze，唯一差异是历史上下文
- 6 份报告已打乱匿名为 report-01~06.md，A/B 归属密封，盲评结束后揭示
- 同股配对关系可从报告标题直接看出（组内对比，本就不需要藏）

## 打分方式（四步走）

1. **配对**：6 个文件分成 3 对。每个文件标题里都有股票名，**同名的两个就是一对**（比如两个"贵州茅台"放一起读）。
2. **读每一对**：一对里的两份报告是同一只股票、相近时间生成的，**唯一区别**是其中一份生成时给 AI 喂了"这只股票过去的分析结论"，另一份没喂。但文件上**不写哪份是哪份**——这正是实验要测的。
3. **每对做个判断**：哪份更有用？还是平手？顺手写一句为什么（比如"03 号写了和上次的对比，变化一目了然"或"两份没感觉出区别"）。
4. **把结果告诉我**：3 对的选择发给我，我拆封对照表统计。

| 配对（看标题同名） | 两个文件（举例） | 哪份更好？**只填编号** | 为什么（一句话） |
|---|---|---|---|
| 贵州茅台 | report-02 + report-05 | 05 | 05 写了和上次的对比 |
| 五粮液 | report-01 + report-06 | 01 |01 写了和上次的对 |
| 前沿生物 | report-03 + report-04 | 03 | 03 写了和上次的对比|

> 文件编号是随机的，**你不需要也不可能知道哪份"有历史"**——凭感觉挑更好的那份，把它的编号写下来就行，剩下的交给我拆封统计。

## 及格线（discovery 文档 E1）
- **有没有用**：3 对里"有历史"版赢 ≥2 对 → 历史对比功能正式引入
- **代价多大**：prompt 长度增量 ≤ +30%（数据见 `prompt-length-stats.csv`，这栏不用你管）
