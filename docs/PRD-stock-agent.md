## 1. 执行摘要

股票分析智能体是 karensAgent 平台的第二个 Agent。支持 A 股与港股，输入股票代码即可生成一份 **10 维度数据采集 + 大模型深度推理**的投研报告，包含综合评分、多空判断、9 大分析模块与信号归因，并支持一键推送到飞书。

相比传统行情软件的"数据罗列"，本 Agent 产出的是有独立逻辑洞察的"阅读材料"：先采集全貌数据，再由大模型结合各维度信息给出有观点的分析结论。

## 2. 背景与目标

| # | 目标 |

## 4. 核心功能

### 4.1 十维度数据采集

围绕一只股票从 10 个维度采集数据，覆盖行情、基本面、资金、风险、舆情全貌：

**实时行情 / 基本信息与估值 / 近期行情走势 / 财务数据 / 股东结构 / 风险评估 / ESG 评级 / 重大事件 / 近期新闻 / 公司公告**

- 近期行情走势维度额外叠加本地自算的技术指标（MA / MACD / BOLL / RSI / KDJ）
- **港股**自动路由到港股数据服务：同样 10 个维度，信息类别与 A 股对齐（ESG 并入"重大事件与 ESG"维度，另有独立"估值水平"维度）

### 4.2 深度投研报告

大模型（推理模型）基于采集数据生成 **9 大模块**报告：

1. 核心结论与操作建议
2. 公司画像与估值定位
3. 财务健康状况
4. 股价走势与资金动向
5. 北向资金 / 主力拆解
6. 股东结构与筹码集中度
7. 催化剂与近期舆情
8. 风险评估与 ESG
9. 散户实战操作指南

同时输出**综合评分（0-100）**、**多空判断（看多 / 震荡 / 看空）**、**信号归因权重**（各维度对结论的贡献方向与占比）。

### 4.3 流式进度体验

前端通过 SSE 实时看到 10 个维度的采集进度——哪个维度进行中、已完成、出错，避免长时间无反馈。

### 4.4 自选股管理

- 自选股增删改查（代码 / 名称 / 备注 / 启停）
- 一键批量分析全部启用的自选股

### 4.5 报告历史与检索

- 历史报告分页列表，支持按代码 / 名称搜索、日期区间、多空判断筛选
- 报告详情页：评分仪表盘 + 9 模块逐项展示 + 信号归因 + 飞书推送

### 4.6 飞书推送

- 报告可一键推送到飞书（独立 Webhook 通道，与 AI 新闻 Agent 互不干扰）
- 可开启"分析完成后自动推送"

## 6. 数据源

| 数据 | 来源 |
|------|------|
| 主要数据源 | 同花顺 iFinD 金融数据终端（MCP 协议，10 维度数据全部经由其股票 / 新闻 / 港股服务） |
| 兜底补充 | 东方财富免费接口（公司名称查询、前复权日 K 线） |
| 技术指标 | 本地自算（MA / MACD / BOLL / RSI / KDJ），不依赖数据源拆分 |

> 免费额度有限速（约 2 QPS），维度间做限速间隔，单次分析约 20-30 秒。

## 7. LLM 分析质量保障

- **三层 Prompt**：角色定义 → 核心分析规则 → JSON Schema 严格约束输出
- **防幻觉三防线**：
  1. 数据守卫：关键字段缺失时拒绝调用大模型，直接返回"数据不可用"
  2. Prompt 约束：要求"数据不足时说不足""结论必须有数据支撑""禁止编造"
  3. 输出校验：解析后检查关键数值是否在合理范围

## 8. 前端界面

四个页面，股票页采用独立的"精密纸媒交易台"设计风格（衬线标题 + 等宽数字 + 深墨配色）：

| 页面 | 功能 |
|------|------|
| 仪表盘 | 搜索分析入口、SSE 维度进度条、公司画像摘要卡片、自选股轮播、最近报告 |
| 报告详情 | 评分环形仪表盘、9 模块组件化展示、信号归因、飞书推送 |
| 历史报告 | 筛选 + 分页报告网格 |
| 配置管理 | 自选股 CRUD、分析维度开关、iFinD 连接状态 |

## 9. 技术要点（简要）

| 项 | 选择 |
|----|------|
| 数据源 | iFinD MCP 金融数据终端（股票 / 基金 / 宏观 / 新闻 / 债券 / 全球股票 / 指数 7 类子服务） |
| 分析模型 | DeepSeek Reasoner（推理模型，OpenAI 兼容接口） |
| 传输方式 | 数据采集 SSE 流式进度 + 报告生成异步 |
| 存储 | 报告表（结构化 JSON + Markdown）、自选股表 |
| 推送 | 飞书机器人 Webhook（独立通道） |
