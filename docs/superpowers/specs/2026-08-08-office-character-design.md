# 自研骨骼化办公人员设计与动画系统

日期：2026-08-08
状态：已批准，待实施

## 背景

首页 3D 办公室当前的两个工作人员由外部 Mixamo FBX 模型（`Seated Idle.fbx`）导入，
仅支持坐姿 idle，且靠运行时实测椅子暴力对齐，**不能站立、走动、交流**。
现改用纯前端 three.js 代码自建人物，实现站立、走动、交流，建模细腻不粗糙。

## 已确认的需求决策（王磊哥哥拍板）

1. 视觉风格：**精致风格化**（圆润曲面 + 细腻五官 + 柔和材质，类似皮克斯风）
2. 交流形态：**脚本对话 + 肢体语言 + 头顶气泡**（预设台词库随机轮换，纯前端）
3. 活动范围：**工位 + 办公室内走动**（坐→站→随机路径点→回工位，对话时到中央面对面）
4. 人物形象：**一男一女**（AI 前沿工位男、股票分析工位女）
5. 交互：**保留点击跳转工位** + **悬停互动反应**（看镜头 + 挥手 + 手形光标）
6. 技术路线：**方案 A 完整骨骼动画**（SkinnedMesh + 手写动画 clip）
7. 不保留：删除 useFBX 加载逻辑与 `Seated Idle.fbx` 依赖，删除诊断面板脚手架

## 人物建模（细腻度核心）

两个角色各约 1.7m 高，风格化但精致，**全程无方块**：

| 部位 | 构建方式 |
|------|---------|
| 头部 | LatheGeometry 平滑头型 + Canvas 程序化绘制五官贴图（眼睛/眉毛/嘴/腮红） |
| 躯干 | 锥形 Lathe 轮廓体现肩胸曲线，衣服壳略大于身体分层 |
| 四肢 | 胶囊体（无棱角）+ 球形肩/髋关节过渡 + 圆头鞋形脚 |
| 头发 | 男士短发贴头皮数片；女士长发多段下垂扁胶囊、发梢渐细 |
| 材质 | MeshStandardMaterial 区分质感：皮肤 roughness 0.55 / 衬衫布料 0.9 / 头发带光泽 |
| 着色 | computeVertexNormals 平滑曲面，复用场景已有光影 |

### 性别差异

- 男士（AI 前沿工位）：短发、肩宽 1.1×、**浅蓝色衬衫**
- 女士（股票分析工位）：长发、肩宽 0.92×、**橙色衬衫**
- 配色固定跟随人物形象（男士浅蓝 / 女士橙色），与工位主题无强制绑定

## 骨骼结构（约 33 根 Bone + SkinnedMesh）

```
Hips → Spine → Chest → Neck → Head
     ├─ 左右 Clavicle → UpperArm → LowerArm → Hand
     └─ 左右 UpperLeg → LowerLeg → Foot
```

每个肢体网格权重就近绑定到对应骨骼，关节过渡自然。
根骨骼 Hips 承载位置移动与朝向，子骨骼负责姿态。

## 动画 clip 清单（手写 keyframe + 正弦采样）

| 动作 | 类型 | 说明 |
|------|------|------|
| idleStand | 循环 | 呼吸起伏 + 重心微摆 + 眨眼 |
| walk | 循环 | 腿部摆幅 + 手臂对侧摆动 + 上身前倾 |
| sit / standUp | 过渡 | 坐进工位椅 / 起身，与工位桌面高度对齐 |
| sitIdle | 循环 | 坐姿打字 + 呼吸 |
| talk | 循环 | 单手/双手手势 + 点头 |
| wave | 一次 | 挥手（悬停反应） |
| reactClick | 一次 | 被点击打招呼后跳转 |

## 行为状态机（走动核心）

```
SIT_IDLE → STAND_UP → WALK_TO(路径点) → FACE → TALK → WALK_TO(回工位) → SIT_DOWN → SIT_IDLE
```

- 预置 6~8 个路径点（工位前、中央会谈区、后侧空地），随机游走，直线 + 平滑转向（quaternion slerp），路径点避开桌椅/装饰
- 会谈调度：随机定时触发 → 两人走向中央面对面 → 轮流说话配手势 → 自然散开回位

## 对话气泡（HTML overlay 层）

世界坐标 → 屏幕坐标投影定位 div 气泡，白底圆角 + 箭头 + 主题色描边，中文清晰。
预置台词库随机轮换。

## 交互

- **点击**：播打招呼动画 → 跳转对应工位（保留现有路由）
- **悬停**：人物看向镜头 + 挥手 + 手形光标（升级现有简单缩放）

## 文件结构与改动

### 新增（放 `frontend/src/three/character/`）

| 文件 | 职责 |
|------|------|
| `buildCharacter.js` | 人物构建器（几何 + 骨骼 + 材质），返回 { skeleton, mesh } |
| `faceTexture.js` | Canvas 五官贴图生成器（眼睛/眉/嘴/腮红） |
| `characterAnimations.js` | 动画 clip 定义（各动作 keyframe） |
| `useCharacterMotion.js` | 状态机 / 移动 / 朝向 / 会谈调度 |
| `CharacterBubble.vue` | 对话气泡 overlay 组件 |

### 改造

| 文件 | 改动 |
|------|------|
| `OfficeWorker.vue` | 用自建角色替换 useFBX；删诊断面板；接入状态机 |
| `OfficeScene.vue` | 挂气泡层 + 会谈调度 |

### 移除

- `Seated Idle.fbx` 依赖、useFBX 加载逻辑
- 原几何体兜底的大方块人（保留但替换为细腻自建角色兜底）

## 容错与测试

- 纯代码无外部资产，无 404 风险；构建器 try/catch 兜底
- 单元测试：骨骼/网格/动画 clip 数量断言、状态机转换正确性
- 边界情况：快速连续点击、两角色在路径点重叠的处理
