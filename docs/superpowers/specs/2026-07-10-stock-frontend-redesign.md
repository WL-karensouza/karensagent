# 股票分析前端重设计 Spec

> 日期：2026-07-10
> 关联：IFIND_REFACTOR_PLAN.md（后端 iFind 数据源重构）
> 范围：除 GitHub 热榜页面外所有前端页面

---

## 1. 设计风格

- **现代简约仪表盘**：浅色系为主，大卡片，恰当留白，强信息层次和可读性
- 延续现有 CSS 变量体系（`--bg-card` / `--accent` / `--text-primary` 等）
- 组件化封装，按职责拆分

---

## 2. 导航与路由

### 导航结构

TopNav 保持现有结构：顶部固定，Agent 标签切换 + 子导航。

股票 Agent 子导航精简为 3 项（去掉"报告 ▾"下拉）：

```
仪表盘 | 历史报告 | 配置管理
```

### 路由表

| 路由 | 页面 | 说明 |
|---|---|---|
| `/agent/stock` | StockDashboard | 搜索 + 5 Tab 维度卡片 + 自选股 + 最近报告 |
| `/agent/stock/report/:id` | StockReport | LLM 综合报告（只展示分析结果） |
| `/agent/stock/history` | StockHistory | 历史报告列表 |
| `/agent/stock/settings` | StockSettings | 自选股管理 + 系统配置 |

### Dashboard 与 Report 关系

```
Dashboard                              Report
   │                                      ↑
   │ 用户点"生成综合报告"                    │
   │ → 后端拿已缓存的5维数据喂DeepSeek       │
   │ → 生成完成后跳转                        │
   └──────────────────────────────────────┘
```

Dashboard 是数据入口，Report 是分析结果。两阶段操作。

## 3. Dashboard 页面

### 3.1 搜索分析栏

**状态机：**

| 状态 | 搜索框 | 按钮 | 额外展示 |
|---|---|---|---|
| 未分析 | 可输入 + Enter 触发 | "开始分析"（可点击） | — |
| 分析中（running） | 禁用 | 禁用 + spinner | "正在采集 {维度名}..." 进度文字 |
| 分析完成（done） | 禁用 | "重新分析" | 右侧出现 "[📝 生成综合报告]" 按钮 |
| 部分完成（partial） | 禁用 | "重新分析" | 同上，顶部显示 warnings 提示条 |
| 分析失败（error） | 可输入 | "重试" | 错误信息提示 |

**生成综合报告按钮**：点击后 → 后端拿已缓存 5 维数据 → 喂 DeepSeek → 生成综合报告 → 存库 → 前端跳转到 `/agent/stock/report/:id`

### 3.2 5 Tab 维度卡片

分析完成后在搜索栏下方出现。每个 Tab 对应一个 fetcher 职责目录。

**Tab 列表：**

| Tab | 标签 | 数据来源 |
|---|---|---|
| 📊 市场行情 | 市场行情 | market_data fetcher |
| 💰 财务分析 | 财务分析 | financials fetcher |
| 📰 新闻事件 | 新闻事件 | news_events fetcher |
| ⚠️ 风险评估 | 风险评估 | risk fetcher |
| 🌍 市场环境 | 市场环境 | market_env fetcher |

**Tab 点击行为**：切换当前维度卡片展示，不触发任何 API 请求。

**Tab 状态样式：**

| 状态 | Tab 样式 | 卡片样式 |
|---|---|---|
| 数据正常 | 正常色 | 全宽结构化数据渲染 |
| 数据缺失 | 灰色文字 + 🔔 图标 | 半透明背景 + 灰色边框 + "⚠️ 数据不可用" + 原因 |
| 当前激活 | 高亮色 + 底部下划线 | 展示中 |

### 3.3 5 张维度卡片内容

具体字段暂不锁定——等 iFind API 跑通后根据实际返回数据再确定字段。当前只确定展示格式：

- 行情数据：表格/网格排列（如 K线、均线、技术指标、资金面）
- 财务数据：五个子维度分区（估值/盈利/成长/偿债/现金流）
- 新闻数据：列表式（标题 + 时间）
- 风险数据：指标网格 + 事件列表
- 市场环境：键值对 + 行业对比表

**数据缺失卡片统一规格：** 半透明背景 + 灰色边框 + 标题 🔔 + 错误原因 + 影响说明，与正常卡片等宽。

### 3.4 下方双栏

| 左栏 | 右栏 |
|---|---|
| ⭐ 我的自选股 | 📋 最近分析报告 |
| 自选股列表 + 快捷分析按钮 | 前5条报告，含评分/判断/时间 |
| 底部 [管理自选股 →] 链接 | 底部 [查看全部 →] 链接 |

下方区域在分析前后始终显示。

## 4. Report 综合报告页

### 4.1 页面结构

```
┌─ 顶栏：← 返回仪表盘 ──────────────────────────────────┐
│                                                        │
│  股票名（代码）综合报告                                    │
│                                                        │
│  ── 评分概览 ──                                         │
│  大号评分数字 / 判断标签 / 评分进度条 / summary 文本        │
│                                                        │
│  ── 各维度分析 ──                                       │
│  每个维度一张结构卡片：信号标签（🟢偏多/⚪中性/🔴偏空）      │
│  + insight 文本段落                                      │
│                                                        │
│  ── 关键价位参考 ──                                      │
│  理想观察区间 / 风控下沿 / 上方压力                        │
│                                                        │
│  ── 信号归因 ──                                          │
│  带权重和方向的各维度贡献分解                              │
│                                                        │
│  ── 观察建议 + 风险提示 + 利好催化 ──                      │
│                                                        │
│  ── 操作区 ──                                            │
│  [📤 推送到飞书]                                          │
│                                                        │
│  生成时间 + 免责声明                                      │
└────────────────────────────────────────────────────────┘
```

### 4.2 状态机

| 状态 | 表现 |
|---|---|
| 加载中 | "正在生成综合报告，DeepSeek 分析中..." + spinner |
| 生成完成 | 渲染全量报告内容 |
| 生成失败 | 错误信息 + [重试] 按钮 |

### 4.3 页面重入

- 已生成过的报告（`id` 在 DB 中存在）：直接加载，不再触发 LLM
- 从历史列表进入：直接加载已存报告

### 4.4 字段设计

综合报告 JSON Schema 暂不锁定，后续单独讨论。

## 5. 历史报告页

当前页面基本保留现有表格结构，增强如下：

- 顶部加搜索框：按股票代码/名称过滤
- 日期范围筛选（可选）
- 判断筛选（看多/震荡/看空）

- 分页保留

## 6. Settings 配置页

### 6.1 自选股管理

保留现有 CRUD 功能：添加、编辑备注、启用/禁用、删除。交互流程不变。

### 6.2 系统配置（新增）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 自动推送飞书 | Toggle 开关 | 关闭 | 分析完成后自动推送综合报告到飞书 |
| 默认分析维度 | 多选 Checkbox | 全部勾选 | 选择分析时默认采集的维度（后期实现按需采集） |
| iFind 连接状态 | 只读指示器 | 运行时检测 | 🟢 已连接 / ⚪ 未配置 / 🔴 连接失败 |

### 6.3 去旧

- 删除"分析技能（6维度）"展示区（旧 skills 目录相关）
- 删除"Agent 各自独立配置"占位文案
