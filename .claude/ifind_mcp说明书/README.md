# ifind
产品展示
面向AI交互的金融数据工具
同花顺MCP金融工具，以MCP协议为基础，在用户AI交互场景或Agent系统中，支持模型自主调用以获取金融数据、金融资讯、金融搜索等能力，为用户AI提供数据支撑和信息依据，降低模型幻觉。

MCP 技术介绍
什么是 MCP
MCP（模型上下文协议）是面向大模型获取外部功能支持场景，用于建立用户端AI和服务商工具的标准化通信协议。MCP工具通过广泛的生态支持实现了极其简便的工具配置，帮助用户迅速将外部能力（如金融数据查询）“插入”自己的AI助手。

mcp

协议架构
MCP 采用客户端-服务端架构：

MCP Server：提供工具（Tools）、资源（Resources）和提示（Prompts）
MCP Client：连接 Server，发现并调用其提供的能力
传输层：支持 stdio、SSE、Streamable HTTP 等多种传输方式
通信流程
客户端发送请求建立连接，获取工具说明
客户端LLM在对话过程中，基于工具说明，自主发起工具请求
服务端接收AI请求，反馈数据查询结果
AI基于数据结果生成内容，完成用户要求

产品优势
解决模型幻觉
AI对话场景中面对专业问题，AI频繁出现编造数据与事实的现象，即使开启网络检索（如通用大模型平台功能），依然可能无法查询到符合需求的数据、或缺乏可靠来源依据。

同花顺MCP工具提供

投研级数据库取数支持
明确可靠的信息来源
解析模糊需求
市面上大多数取数工具基于API接口封装，对用户问题清晰度要求高，例如准确的证券代码、公告标题、数据指标等元信息。对于用户模糊需求的支持能力不足（如”三花盾安最新一期的增速”、”锂电池公司的估值水平”）

同花顺MCP工具提供

自然语言提问方式
模糊表达自动匹配
智能条件选股选基
降低开发成本
传统金融数据服务以数据库、API方式提供，用户需承担对接数据的额外开发成本，还可能涉及自研AI取数系统，一旦平台变动需重新开发。

同花顺MCP工具提供

复制粘贴一段文字即对接任意MCP平台
内置取数算法，用户仅需发送数据需求

基础数据
基础数据函数将iFinD终端中的各类金融品种的数据浏览器指标进行汇总统一，目前支持A股股票、基金的上市品种，覆盖基本资料、财务数据、日频行情信息、持仓信息、各类分析指标等数据。 （备注：高频实时行情与盘口数据暂不支持MCP工具服务）

宏观经济数据
投研级宏观经济数据库，具体包括世界经济数据、全球经济数据、中国经济数据、区域经济数据、行业经济数据、利率走势数据、商品数据和特色数据。

公告资讯搜索
支持A股、基金、港美股相关公告及金融资讯语义搜索，面向AI应用场景的：支持通过关键词或搜索内容等模糊请求进行语义检索；同时采用相关段落反馈（而非长文本）以节省用户上下文资源。
